# FSM for DDKND

## Installation

```pwsh
python -m pip install -e .\tools\fsm
```


## Type convertion

| DSL Type | C++ Generated Type |
| --- | --- |
| bool | bool |
| int | std::int32_t |
| UVec2 | ddknd::math::uVec2 |
| UVec3 | ddknd::math::uVec3 |
| FVec2 | ddknd::math::Vec2f |
| FVec3 | ddknd::math::Vec3f |
